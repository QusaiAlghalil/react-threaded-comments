# react-threaded-comments

> **Early development.** This version is a placeholder. The components are not usable yet.

A Facebook-style threaded comment section for React, with a headless storage adapter so you can plug in any backend.

## Planned for v0.1

- Nested replies
- Edit and delete
- Reactions (like, love, haha, wow, sad, angry)
- Optimistic updates with rollback on error
- Theming with CSS variables, including dark mode
- Accessible: keyboard support and ARIA labels

Follow progress on [GitHub](https://github.com/QusaiAlghalil/react-threaded-comments).
